# Flipped for Google Slides

[English](README.md) | **中文**

一份 Google Slides 的交互式产品提案：AI 先讲，你来挑错。网页界面为英文。

| 章节 | 功能 | 实现方式 |
|---|---|---|
| 01 | 反向排练 | Gemini 为演示稿生成讲稿（可用浏览器语音朗读），里面埋了 6 个问题。你标出讲错的、不像你说的、漏讲的要点，揭晓后显示你吃透了哪几页。 |
| 02 | 听众注意力回放 | 在浏览器里录一遍排练，或使用示例。逐秒的注意力模型生成可拖动的曲线，标出走神、困惑和记忆点。 |
| 03 | 下一次排练计划 | 按漏掉的问题和注意力下滑给幻灯片排序，Gemini 写教练点评。 |

## 运行

在仓库根目录执行：

```bash
npx -y http-server . -p 5173 -c-1
```

打开 http://localhost:5173/slides-flipped/ 。演示时用 `→` / 空格翻页，`←` 返回。录音功能需要 Chrome。

## Gemini key（可选）

点右上角的 **Data sources** 填写。没有 key 时使用示例讲稿和示例点评。
