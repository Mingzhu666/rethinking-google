# Looped In for Gmail

[English](README.md) | **中文**

一份 Gmail 的交互式产品提案：家人防诈守护。老人遇到高风险诈骗时，她选择的家人会收到提醒——只传风险，不传邮件。网页界面为英文。

| 章节 | 功能 | 实现方式 |
|---|---|---|
| 01 | 双向同意 | 老人选择守护人，能看到守护人收到的每条提醒，随时可以关闭。 |
| 02 | 三层检测、先停一下、通知家人 | 规则预筛 → 链接信誉（Google Safe Browsing 官方测试页）→ 只有被标记的邮件才交给 Gemini 判断意图。高风险时用一句不含正文的话通知守护人；点击危险链接时弹出"先停一下"，可一键给女儿打电话。 |
| 03 | 对话级识别 | 按阶段（建立信任、隔离、推销、索要）为 6 周往来打分，在要钱之前越过通知守护人的阈值。 |

## 运行

在仓库根目录执行：

```bash
npx -y http-server . -p 5173 -c-1
```

打开 http://localhost:5173/gmail-looped-in/ 。演示时用 `→` / 空格翻页，`←` 返回。

所有邮件都是为演示编写的，唯一的"危险"链接是 Google 官方的安全浏览测试页。不使用任何付费 API；第三层可使用免费的 Gemini key（可选），没有 key 时显示示例结果。
