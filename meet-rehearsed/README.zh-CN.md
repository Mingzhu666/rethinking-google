# Meet, Rehearsed

[English](README.md) | **中文**

一份为现场演示打造的 Google Meet 交互式产品提案：把复盘前移到会前。网页界面为英文。

| 章节 | 功能 | 实现方式 |
|---|---|---|
| 01 | 会议飞行模拟器 | 确定性模拟引擎快进播放议程（时间轴、风险雷达、失败事件），给出修复建议后重新模拟。Gemini 负责草拟会前私信、解析粘贴的议程。 |
| 02 | 提问演练室 | Gemini 预测最难的三个问题并点评你的回答。可以打字，也可以直接说（浏览器语音识别）。 |
| 03 | 会议镜子 | 本地计算发言占比、打断次数、口头禅，加上 Gemini 的"比赛录像"式复盘，最后给出一个下次的改进目标。 |

## 运行

在仓库根目录执行：

```bash
npx -y http-server . -p 5173 -c-1
```

打开 http://localhost:5173/meet-rehearsed/ 。演示时用 `→` / 空格翻页，`←` 返回。

## Gemini key（可选）

点右上角的 **Data sources** 填写。key 只保存在本机浏览器，并与同一地址下的其他演示共用。没有 key 时自动回退到缓存，再到示例数据。

Gemini 免费额度的响应时间波动较大（常见 10–25 秒）。现场演示前先完整走一遍让结果缓存下来，再勾选 **Safe demo mode**。

## 隐私

风险评估针对议程结构，不针对个人。转写稿在浏览器本地分析，只有填写了 key 时文本才会发送给 Gemini。
