# Priced for Google Calendar

[English](README.md) | **中文**

一份 Google Calendar 的交互式产品提案：让每场会议显示它真实的成本。网页界面为英文。

| 章节 | 功能 | 实现方式 |
|---|---|---|
| 01 | 会议真实成本 | 人数 × 时长 × 组织平均时薪，再加上碎片化成本（被会议切碎的 90 分钟以上专注时段）。建会时实时计价，超过阈值必须填写理由并由 Gemini 审核。可导入 `.ics` 为你自己的日历计价。 |
| 02 | 匿名否决票 | 参会者私下评价会议价值，满 3 票才解锁结果，组织者只能看到分布。会议取消后由 Gemini 起草异步更新。 |
| 03 | 每周账单 | 团队会议花费逐项列出，实时更新。 |

## 运行

在仓库根目录执行：

```bash
npx -y http-server . -p 5173 -c-1
```

打开 http://localhost:5173/calendar-priced/ 。演示时用 `→` / 空格翻页，`←` 返回。

## Gemini key（可选）

点右上角的 **Data sources** 填写。没有 key 时，邀请审核和异步更新使用示例回复。
